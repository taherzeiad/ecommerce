# خطة إضافة بيانات المنتجات بدون لوحة تحكم (Admin Dashboard)

بما أنك تستخدم **Supabase** في مشروعك وتريد إضافة بياناتك الخاصة لعرضها للمستخدم دون الحاجة لبناء لوحة تحكم إدارية، لديك ثلاث طرق فعالة. إليك الخطة الشاملة:

## المقارنة بين الطرق المتاحة

| الطريقة | الجهد | القابلية للتحديث | الاستخدام الأمثل |
| :--- | :--- | :--- | :--- |
| **Supabase Dashboard** | منخفض جداً | سهلة جداً (عن طريق الموقع) | الإنتاج (Production) والبيانات الحقيقية |
| **ملف JSON محلي** | متوسط | متوسط (يتطلب تحديث الكود) | العروض التجريبية (Demo) |
| **Hardcoded (Mock)** | منخفض | صعبة (تعديل مباشر في الكود) | الاختبارات السريعة فقط |

---

## الخطوة الأولى: استخدام Supabase كـ "لوحة تحكم جاهزة" (الخيار الأفضل)

بما أن `SupabaseProductRepository` موجود بالفعل، يمكنك استخدام موقع Supabase لإدارة بياناتك:

1.  **تجهيز الجداول:** تأكد من وجود جدول باسم `products` يحتوي على الأعمدة التالية (بناءً على `ProductModel`):
    *   `id` (String/UUID)
    *   `name` (Text)
    *   `category_name` (Text)
    *   `price` (Float/Numeric)
    *   `oldPrice` (Float/Numeric)
    *   `rating` (Float)
    *   `reviewCount` (Int)
    *   `description` (Text)
    *   `images` (Text Array - `text[]`)
    *   `is_flash_deal` (Boolean)

2.  **إضافة البيانات:**
    *   ادخل على [Supabase Dashboard](https://supabase.com/dashboard).
    *   انتقل إلى **Table Editor**.
    *   اضغط على **Insert row** وأضف بيانات منتجاتك يدوياً.
    *   بالنسبة للصور، يمكنك رفعها في قسم **Storage** ونسخ الروابط العامة (Public URLs) ووضعها في مصفوفة الصور.

3.  **تفعيل المستودع:** تأكد من أن تطبيقك يستخدم `SupabaseProductRepository` بدلاً من الـ Mock في ملف الـ `Injection Container` أو مزود الخدمة.

---

## الخطوة الثانية: استخدام ملف JSON محلي (بدول إنترنت)

إذا كنت تفضل تخزين البيانات داخل التطبيق نفسه:

1.  **إنشاء ملف البيانات:**
    *   أنشئ مجلد `lib/assets/data/`.
    *   أضف ملفاً باسم `products.json` وضع فيه بياناتك:
    ```json
    [
      {
        "id": "101",
        "name": "المنتج الخاص بي",
        "category": "الأجهزة",
        "price": 1500.0,
        "description": "وصف المنتج هنا...",
        "images": ["assets/images/product1.png"],
        "isFlashDeal": true
      }
    ]
    ```

2.  **تعريف الملف في `pubspec.yaml`:**
    ```yaml
    flutter:
      assets:
        - lib/assets/data/products.json
    ```

3.  **إنشاء `JsonProductRepository`:** قم بإنشاء مستودع يقرأ من هذا الملف باستخدام `rootBundle.loadString()`.

---

## الخطوة الثالثة: إدارة الصور (Assets vs Links)

*   **روابط مباشرة (Links):** أسهل طريقة، تضع روابط صور من الإنترنت مباشرة في قاعدة البيانات.
*   **صور محلية (Local Assets):**
    *   ضع الصور في `lib/assets/images/`.
    *   عرفها في `pubspec.yaml`.
    *   استخدم مسار الصورة (مثل `assets/images/item.png`) كـ String في حقل الصور في قاعدة البيانات أو الـ JSON.

## التوصية النهائية

أوصيك باستخدام **الخيار الأول (Supabase Table Editor)** لأنه:
1.  لا يتطلب منك كتابة كود إضافي.
2.  يسمح لك بتغيير الأسعار أو إضافة منتجات جديدة وتظهر فوراً عند المستخدم دون تحديث التطبيق.
3.  يستفيد من الـ Repository الذي قمت بإنشائه بالفعل.

**هل تريد مني البدء بتجهيز جدول Supabase لك أو المساعدة في إنشاء مستودع JSON محلي؟**
